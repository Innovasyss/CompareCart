# CompareCart

CompareCart is a prototype price-comparison web application that helps users compare product prices across platforms and demonstrates modern front-end and cloud integration skills.

**Purpose:** This project was built for educational, portfolio, and career placement purposes. It serves as a technical showcase and is not a commercial product.

## 🚀 Key Features

*   **Product Listing & Comparison:** Browse a grid of products and view price comparisons between major retailers (e.g., Amazon vs. Flipkart).
*   **Search & Sort:** Functional search bar with sorting capabilities (Price: Low to High, High to Low, Popularity (simulated)).
*   **User Accounts:** Secure **Login and Registration** functionality powered by Firebase Authentication.
*   **Favorites:** Logged-in users can save products to a "Favorites" list, persisted via the Firebase Realtime Database.
*   **User Profile:** A dedicated profile page allowing users to view and update their details (with logic restricting update frequency).
*   **Responsive UI:** A mobile-friendly design featuring a hamburger menu, adaptive grids, and a branded onboarding experience.
*   **Sponsored Layouts:** Includes UI placeholders for sponsored content and affiliate links to demonstrate commercial layout awareness.

## 🛠️ Tech Stack

*   **Frontend:** HTML5, CSS3, JavaScript (ES6+)
*   **Backend / Cloud:** Firebase Authentication, Firebase Realtime Database
*   **Styling:** Custom CSS (Flexbox, Grid, CSS Variables)

## 📱 UI & Design Notes

*   **Responsive Design:** The application adapts seamlessly to different screen sizes, from desktop monitors to mobile phones.
*   **Branded Onboarding:** The login and registration screens feature a polished, branded aesthetic to enhance user trust.

## ⚠️ Prototype Disclaimer

This project is a **prototype created for educational and portfolio purposes**.

*   **Mock Data:** Product data and prices are simulated for demonstration purposes.
*   **Placeholders:** Some features and integrations (such as live API fetching or payment gateways) are placeholders to represent future functionality.

## 💻 How to Run Locally

To view this project on your local machine:

1.  **Clone the repository:**
    ```bash
    git clone https://github.com/Innovasyss/CompareCart.git
    ```

2.  **Navigate to the project directory:**
    ```bash
    cd CompareCart
    ```

3.  **Run the application:**
    *   Open `index.html` (or the entry file containing the login form) in your web browser.
    *   *Tip:* For the best experience with Firebase, use a local development server (e.g., the "Live Server" extension in VS Code).
